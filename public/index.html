Where do I get a token?
  1. In BookStack, open your profile menu → My Account → Access & Security → in the API Tokens section, click Create Token.
  2. Copy the Token ID and Token Secret into the fields above.
  3. Your BookStack role needs the Access System API permission — ask an admin if the API Tokens section is missing.
